
# Second Brain — Operating Rules

## Purpose
Maintain a reliable, growing personal knowledge base for
backend engineering, career development, and personal learning.

## Storage
- `raw/` contains original sources.
- Never modify or overwrite original sources.
- `wiki/` contains AI-maintained Markdown knowledge pages.
- Use relative Markdown links or Obsidian wikilinks consistently.
- `wiki/index.md` catalogs important knowledge pages.
- `wiki/log.md` records wiki changes.

## Ingest
When I ask you to ingest a source:
1. Read the original source.
2. Identify its main ideas and useful takeaways.
3. Create a concise source summary.
4. Update existing concept pages when appropriate.
5. Create new concept or entity pages only when useful.
6. Link related pages and update the index.
7. Record changes in the log.
8. Preserve disagreements and contradictory evidence.

## Query
- Read the index before exploring relevant pages.
- Answer using evidence from the wiki.
- Cite the pages supporting important claims.
- Distinguish facts, opinions, and inferences.
- Say when the available evidence is insufficient.
- Suggest saving valuable new insights to the wiki.

## Quality
- Prefer clear, concise explanations.
- Avoid duplicate pages and unnecessary abstractions.
- Preserve source attribution and URLs.
- Do not invent citations or pretend to have read inaccessible sources.
- Ask before deleting pages or making destructive changes.

## Privacy
- Never intentionally ingest passwords, API keys, tokens,
  or confidential employer information.
- Ask before transmitting private source material to external services.

## Maintenance
When asked to lint the wiki, check broken links,
duplicate pages, missing index entries, contradictions,
and outdated information.
